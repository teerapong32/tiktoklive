วิธีใช้ (ทำครั้งเดียวแล้วใช้ได้เรื่อยๆ)
1) ติดตั้ง Node.js (เวอร์ชัน LTS) จาก nodejs.org
2) ดับเบิลคลิก start.bat (Windows) หรือรัน ./start.sh (Mac/Linux) รอติดตั้งครั้งแรก แล้วเบราว์เซอร์จะเปิด http://localhost:3000
3) ใส่ชื่อ TikTok -> เลือกเทมเพลต -> เริ่ม Live (ต้องกด "เริ่ม Live" ในแอป TikTok ของคุณก่อน คอมเมนต์ถึงจะเข้า)
4) ใน TikTok LIVE Studio / OBS เพิ่มแหล่งภาพ "Window Capture" เลือกหน้าต่างเบราว์เซอร์ แล้วกด H เพื่อซ่อนแผงควบคุม
หมายเหตุ: ตัวดึงคอมเมนต์เป็นไลบรารีไม่เป็นทางการ (reverse engineering) TikTok เปลี่ยนระบบเมื่อไรอาจหยุดทำงานจนกว่าไลบรารีจะอัปเดต
ถ้าเชื่อมต่อไม่ผ่านเพราะติดเรื่องการเซ็นคำขอ ให้ตั้งตัวแปร SIGN_API_KEY ตามเอกสารของไลบรารี
